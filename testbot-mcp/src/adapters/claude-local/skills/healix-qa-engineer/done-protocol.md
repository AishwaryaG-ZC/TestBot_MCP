# DONE Protocol

Write `DONE` only when:

- every targeted AC has at least one tagged test;
- all tests are grounded in real source, routes, selectors, or endpoints;
- known bad tests have been repaired or removed;
- unresolved ambiguity has been asked through the available user-question tool or recorded as a skipped coverage question.

The orchestrator may ignore premature `DONE` and continue the QA loop.
